Documentation

Everything you need to know about USB Shield.

Overview

USB Shield is a Windows desktop application designed to protect USB flash drives from shortcut viruses, autorun malware, and hidden trojans. It automates the process of backing up files, reformatting the drive to NTFS, locking the root directory, and restoring your data into a protected folder.

The tool is built with Python and Tkinter, packaged as a standalone executable for easy distribution and use.

How It Works

1

Backup

Copies all files from the USB drive to Desktop\USB_Backup_<drive> using Robocopy, excluding system files and shortcuts.

2

Format

Quick-formats the USB drive to NTFS, ensuring a clean filesystem free from malware.

3

Lock Root

Applies Windows ACL rules to deny write and append access to the root of the USB drive, preventing malware from dropping files there.

4

Restore

Restores your backed-up files into a My_Files folder with full access permissions, then cleans up the temporary backup.

FAQ

Is my data safe?

Yes. The tool creates a full backup on your Desktop before formatting. However, always keep a separate backup of important data.

Why does it need admin rights?

Formatting a drive and changing NTFS permissions requires administrator privileges. The app will prompt for UAC approval on launch.

Can I use this on multiple USB drives?

Yes. Select any connected USB drive from the dropdown and run the protection process.

What does "Root Lock" actually do?

It denies Write Data and Append Data permissions to the root of the USB drive for all users. This prevents malware from creating hidden files, shortcuts, or scripts at the root level.
